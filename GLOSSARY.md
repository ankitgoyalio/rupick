# Rupick

Rupick finds exact image matches and duplicate content within a selected project.

## Language

**Project session**:
One opening of a project folder in a window, together with its incoming images and inspection state. Reopening the same folder begins a new project session; adding incoming images continues the current one.
_Avoid_: Project folder (when referring to a session)

**Incoming batch**:
A group of images submitted together for comparison in a project session. Images retain their order within the batch, and batches retain their submission order.
_Avoid_: Drop (when including images submitted through the file picker)
