# Local session restoration with validated reviews

For #10, persist open project sessions as a versioned JSON archive in sandbox-local UserDefaults, behind `SessionStorage`. Keep canonical window identity separate from the granted project URL. Store read-only security-scoped bookmarks for project roots and incoming files, ordered incoming references, sidebar selection, representation selections, and review records with their content versions and original match identities. A completed comparison rebuilds results and applies the existing review freshness policy before making a restored outcome current. Results, decoded pixels, thumbnails, and pending picker or drop operations are not persisted.

This extends the session-only review decision in ADR 0001. Explicitly closing a window ends its session, while quitting preserves open sessions. SwiftUI value-based windows are reopened from the archive once at launch; native window restoration is disabled to avoid a second source of window identity. An AppKit termination callback checkpoints before teardown, because disappearing views cannot distinguish closure from application termination.

Retain App Sandbox, user-selected read-only access, and `com.apple.security.files.bookmarks.app-scope` for persistent grants. Resolve bookmarks without presenting implicit UI, validate project readability while holding access, and renew bookmarks while leases are active. Failed incoming grants keep the entry unavailable until Locate provides a new grant; missing files retain their review baseline for the same content to be reconnected. Project access failure retains a failed session with Locate Project. Remove only changes session membership. Workers and previews continue owning separate balanced access leases.

Archive version 1 uses Codable JSON with a top-level `version` and ordered `projects`. Each project contains `identity`, a `reference` with `url` and optional bookmark data (JSON base64), ordered `incoming` references and review records, and optional `selection`. Unknown versions, corrupt archives, duplicate identities or incoming URLs, and non-file references show restoration guidance. Write failures show save guidance. This is local preference data, not a portable document or synchronized database, and contains paths and content fingerprints but no image bytes. Future schema changes require an explicit migration or visible recovery. The existing ten-entry Recent Projects format remains independent of the open-session archive.
